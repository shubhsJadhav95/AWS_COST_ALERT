# 📊 AWS Cost Alert System

A full-stack **Serverless AWS Cost Alert System** built using Spring Boot and AWS services that monitors AWS usage and sends email alerts when cost thresholds are exceeded.

---

## 🚀 Features

- AWS cost monitoring alerts
- Email notifications using AWS SNS
- Serverless-ready backend (AWS Lambda compatible)
- REST APIs using Spring Boot
- React.js frontend dashboard
- Secure environment-based configuration

---

## 🧰 Tech Stack

### Backend
- Spring Boot
- Maven
- AWS Lambda
- AWS SNS
- AWS CloudWatch

### Frontend
- React.js
- Axios / Fetch API

### Cloud Services
- Amazon Web Services (AWS): Lambda, SNS, IAM, CloudWatch

---

# Project Setup Guide

## 🧠 Backend Setup (Spring Boot)

### 1. Navigate to backend
```bash
cd backend/aws-alert
```

### 2. Build project
```bash
mvn clean install
```

### 3. Run backend
```bash
mvn spring-boot:run
```

Backend runs at: `http://localhost:8080`

---

## 💻 Frontend Setup

### 1. Navigate to frontend
```bash
cd frontend
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start frontend
```bash
npm start
```

Frontend runs at: `http://localhost:3000`
